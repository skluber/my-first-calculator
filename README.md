# Calculator

A fully functional calculator built with JavaScript, HTML, and CSS.

The application performs standard arithmetic operations while providing a clean and responsive user interface. This project focuses on DOM manipulation, event handling, and application state management without relying on external frameworks.

## Live Demo

🚀 **Live Demo:** https://skluber.github.io/my-first-calculator/

## Features

* Addition, subtraction, multiplication, and division
* Decimal number support
* Clear and delete functionality
* Keyboard and mouse input support
* Error handling for invalid operations
* Responsive design
* Real-time display updates

## Built With

* JavaScript (ES6)
* HTML5
* CSS3

## Concepts Practiced

This project was built to strengthen core JavaScript skills, including:

* DOM manipulation
* Event handling
* Application state management
* Functions and modular logic
* Conditional statements
* Keyboard event listeners
* User input validation
* Responsive user interface design

## How It Works

1. Enter numbers using the calculator buttons or keyboard.
2. Select an arithmetic operation.
3. Enter the second number.
4. Press equals (`=`) to calculate the result.
5. Continue calculations or clear the display to start over.

## Installation

Clone the repository:

```bash
git clone https://github.com/skluber/my-first-calculator.git
```

Move into the project directory:

```bash
cd my-first-calculator
```

Open `index.html` in your browser.

Alternatively, use a local development server such as VS Code Live Server.
